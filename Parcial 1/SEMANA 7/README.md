# SEMANA 7 - Restaurante App

Sistema modular en Python que permite registrar, listar y buscar productos y clientes mediante un menú interactivo de consola.

## Estructura

- **restaurante_app/** : aplicación principal con modelos, servicios y punto de entrada.
  - **modelos/** : Producto (constructor + @property/@setter) y Cliente (@dataclass).
  - **servicios/** : Restaurante (servicio principal) + documentación de guía.
  - **main.py** : menú interactivo.

- **tests/** : pruebas mínimas para validar comportamiento.

## Documentación

Consulte los archivos dentro de `restaurante_app/servicios/` para guías y ejemplos:
- `GUIA_DIDACTICA.md` : conceptos aplicados.
- `INICIO_RAPIDO.txt` : cómo ejecutar.
- `EJEMPLO_INTERACTIVO.md` : pasos de prueba manual.
- `ESTRUCTURA_FINAL.md` : diagrama del proyecto.
